# Контур — прототип редактора помещения

Изолированный frontend-прототип построения комнаты по точным миллиметровым координатам. Он не использует backend, ORM или базу данных и может позднее встраиваться в Quart как собранная статическая страница.

## Запуск

```bash
cd modules/constructor
npm install
npm run dev
```

Сборка для проверки:

```bash
npm run build
npm run preview
```

## Архитектура

- `RoomModel` — единственный источник истины для точек, стен, размеров и состояния контура. Все значения хранятся в миллиметрах.
- `SceneManager` — отображает модель в Three.js, переводя `1000 мм` в `1` единицу сцены. Управляет двумя камерами, сеткой, стенами, точками, полом и размерными подписями.
- `EditorController` — обрабатывает построение, выбор, перемещение точек, точный ввод и удаление.
- `SnapManager` — привязка к сетке, точкам, горизонтали, вертикали и углам 45°.
- `CommandManager` и команды — история добавления, перемещения, удаления и изменения параметров.
- `EditorUI` — синхронизирует панели и строку состояния с моделью редактора.

Three.js не хранит проектные координаты и всегда перестраивается из `RoomModel`.

## Управление

- `B` — построение комнаты;
- `V` — выбор;
- `Enter` — точный ввод длины строящейся стены;
- `Escape` — отмена незавершённого сегмента;
- `Delete` — удаление выбранной стены;
- `Ctrl+Z` — отмена;
- `Ctrl+Shift+Z` или `Ctrl+Y` — повтор.

В режиме сверху камера панорамируется и масштабируется средствами мыши. В 3D доступны вращение, панорамирование и масштабирование.

## Реализовано

- последовательное построение стен на плоскости XZ;
- точные размеры в миллиметрах и размерные подписи;
- привязки к сетке, точкам, осям и 45°;
- замыкание контура на первую точку;
- проверка самопересечений;
- объёмные стены и пол по замкнутому контуру;
- ортографический вид сверху и перспективный 3D-вид;
- выбор и удаление стен;
- изменение длины, высоты и толщины;
- перетаскивание точек с обновлением геометрии;
- undo/redo для основных изменений;
- адаптация интерфейса для настольных экранов от 1100 px.

## Ограничения прототипа

- поддерживается один последовательный контур без внутренних отверстий;
- нет дверей, окон, мебели, материалов и сохранения;
- точка перемещается только в виде сверху;
- при недопустимом самопересечении перенос точки откатывается;
- размеры показывают длину сегмента без выносных линий CAD;
- Vite используется только для локальной разработки и сборки.
